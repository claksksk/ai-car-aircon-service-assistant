# Project 3: AI-Assisted Car Aircon Service & Diagnostic Assistant

## 1. Project Overview
An intelligent web module designed to assist vehicle owners in diagnosing automotive air-conditioning issues and recommending appropriate maintenance services before placing a booking.

## 2. Specialization Area
- **IT Specialization:** Web Development & AI Literacy / Integration
- **Core Competencies:** PHP Dynamic Scripting, Rule-based / API Assistant Logic, Responsive UI with Bootstrap 5, and Session Management.

## 3. Live System Demo
- **Live URL:** [http://car-aircon-booking.infinityfreeapp.com](http://car-aircon-booking.infinityfreeapp.com)

## 4. Key Features
- **Interactive Chat Interface:** Natural conversation flow for gathering vehicle symptoms.
- **Service Recommendation Engine:** Automated mapping of customer-reported issues (e.g., warm air, strange noise, weak airflow) to repair services.
- **Direct Booking Integration:** Seamless transfer from chat recommendation to the appointment booking form.

## 5. Technologies Used
- **Front-End:** HTML5, CSS3, JavaScript, Bootstrap 5
- **Back-End:** PHP 8.x
- **Database:** MySQL / MariaDB (phpMyAdmin)
- **Deployment Platform:** InfinityFree Web Hosting
